# 🌌 Retro Hyprland Setup for FIREBAT U6C

Полностью автоматизированная, минималистичная TUI/CLI сборка **Retro** для тайлового композитора **Hyprland** на базе **Arch Linux**. Оптимизирована под экран 2.5K @ 120Hz и управление исключительно с клавиатуры.

---

## 🚀 Особенности сборки
* **Управление обоями:** Свежий стек на базе движка `awww` со скриптами автосмены.
* **Быстрый медиа-просмотр:** Связка `yazi` + `imv-dir` для быстрого перелистывания картинок обычным **Пробелом** и `mpv` для видео.
* **Современный код:** Легковесный и сверхбыстрый редактор **Zed IDE**.
* **Красивый старт:** Экран входа **SDDM** с кастомной ретро-заставкой `lw.png`.
* **Удобные TUI утилиты:** Управление сетью (`wlctl`), звуком (`pulsemixer`) и Bluetooth (`bluetui`) прямо в плавающих окнах.

## 🛠️ Структура репозитория

```text
├── configs/             # Папка со всеми dot-файлами
│   ├── fuzzel/          # Конфиг лаунчера приложений
│   ├── hypr/            # Настройки Hyprland и скрипты
│   ├── kitty/           # Эмулятор терминала
│   └── waybar/          # Статус-бар (шрифты Font Awesome 6)
├── wallpaper/
│   └── lw.png           # Твои нарисованные космические обои
└── install_hyprland.sh  # Главный скрипт автоматической установки
```

---

## ⚡ Быстрая установка

1. Склонируй этот репозиторий на свой Arch Linux:
```bash
git clone https://github.com
cd ИМЯ_РЕПОЗИТОРИЯ
```

2. Сделай скрипт исполняемым и запусти его (от имени **обычного пользователя**, не root):
```bash
chmod +x install_hyprland.sh
./install_hyprland.sh
```

3. После завершения установки удали старый GNOME/Cosmic (если нужно) и перезагрузи компьютер:
```bash
sudo systemctl reboot
```

## ⌨️ Горячие клавиши (Шпаргалка)

### Основные программы:
* `SUPER + Return` — Открыть терминал (`kitty`)
* `SUPER + D` — Лаунчер приложений (`fuzzel`)
* `SUPER + N` — Браузер (`zen-browser`)
* `SUPER + E` — Файловый менеджер (`yazi`)
* `SUPER + Q` — Закрыть активное окно
* `Ctrl + Alt + Delete` — Выход из Hyprland

### Утилиты в плавающих окнах:
* `SUPER + W` — Управление сетью (`wlctl`)
* `SUPER + B` — Управление Bluetooth (`bluetui`)
* `SUPER + A` — Микшер звука (`pulsemixer`)
* `SUPER + Shift + P` — Взять цвет с экрана (`hyprpicker` с автокопированием)

### Мультимедиа и Скриншоты:
* `Ctrl + Alt + W` — Сменить обои вручную
* `SUPER + Shift + S` — Скриншот области (сохраняется в `~/Pictures/Screenshots` и копируется в буфер)
* `Ctrl + Alt + Print` — Начать/остановить запись экрана (сохраняется в `~/Videos`)
